## Question 4: MPC006-ETHICS
**Title:** Discuss the various ethical issues, concerns, and ethics involved in psychological assessment and testing.

### Table: Common Fallacies in Psychological Assessment

| Fallacy | Description |
|---------|-------------|
| Mismatched Validity | Using a test for a population/purpose not validated for |
| Confirmation Bias | Seeking evidence that confirms pre-existing beliefs; ignoring contradictions |
| Retrospective vs. Predictive | Assuming past accuracy equals future predictive power |
| Unstandardising Tests | Altering administration/norms, invalidating results |
| Low Base Rates | Ignoring rarity of condition, leading to high false positives |
| Dual High Base Rates | Misinterpreting predictive power when both condition/test rates are high |
| Perfect Conditions | Assuming ideal lab results apply to messy real-world settings |
| Financial Bias | Letting reimbursement/litigation fees influence test choice/interpretation |
| Observer Effects | Ignoring how recording/observers alter client behavior |
| Uncertain Gate Keeping | Lack of rigor in determining who qualifies for assessment |

## Question 5: MPC006-FALLACIES
**Title:** Additional advanced fallacies in psychological assessment.

### Table: Advanced Fallacies

| Fallacy | Description |
|---------|-------------|
| Barnum Effect | Accepting vague, general descriptions as personally meaningful |
| Blind Interpretation | Interpreting test data without behavioral observations or history |
| Overconfidence in Actuarial Data | Ignoring clinical judgment entirely in favor of statistical predictions |
| Cultural Decontextualization | Applying Western norms without considering cultural factors |
| Test Worship | Treating test scores as infallible truth rather than samples of behavior |
| Pathologizing Normal Variation | Misinterpreting normal personality variations as pathology |
| Linear Assumption Fallacy | Assuming linear relationships between variables when they may be curvilinear |

## Question 7: MPC006-DESC-PREDICT
**Title:** Differentiate between descriptive and predictive assessment.

### Table: Descriptive vs Predictive Assessment

| Dimension | Descriptive Assessment | Predictive Assessment |
|-----------|----------------------|---------------------|
| Focus | Current state/functioning | Future outcomes/behavior |
| Time Orientation | Present-focused | Future-oriented |
| Methods | Interviews, observations, current testing | Risk assessments, prognostic tools |
| Use Case | Diagnosis, case formulation | Treatment planning, risk management |
| Accuracy | Higher (based on observable data) | Lower (inherent uncertainty) |
| Examples | MSE, symptom checklists | Violence risk, suicide risk, treatment response prediction |
| Data Sources | Direct observation, self-report | Historical data, statistical models |
| Limitations | May not guide intervention | Subject to base rate problems |
| Ethical Concerns | Minimal | Potential for self-fulfilling prophecies |
| Reliability | Generally higher | Generally lower |
| Validity | Content/criterion validity emphasized | Predictive validity critical |
| Clinical Utility | Essential for diagnosis | Essential for prognosis |

### Table: Critical Metrics

| Metric | Description |
|--------|-------------|
| Sensitivity | True positive rate |
| Specificity | True negative rate |
| Positive Predictive Value | Probability that positive result is accurate |
| Negative Predictive Value | Probability that negative result is accurate |
